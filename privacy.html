Privacy Policy

Last updated November 25, 2026

Horror Story Studio is operated by the owner of the What the Night Hides YouTube channel for that channel’s production and publication workflow. The studio application and this static information site are separate.

Google and YouTube data we access

The application uses YouTube API Services through YouTube Data API v3. The owner grants access through a Google OAuth consent screen. The desktop authorization requests https://www.googleapis.com/auth/youtube.force-ssl to verify the authorized channel and manage the owner’s uploads. Offline access allows the notebook to obtain an access token during a later owner-run session.

The integration reads the authorized channel’s identifier and title. It reads the owner’s relevant video and playlist identifiers, metadata, processing results, visibility and scheduling settings, caption tracks, and thumbnail status. It may download the serving caption file to compare it with the approved local captions. The integration does not request Gmail or contacts access.

The notebook may also use a separately consented Google Drive credential scoped to specific files. It uses an owner-authorized project folder to verify transfers and retain project inputs, output media, and production records. If the Drive acceptance check is run, it reads the Drive account email to confirm the owner and stores a hash of the matched email in its evidence record.

How we use and share the data

We use YouTube data to confirm the channel, avoid duplicate uploads, verify processing and metadata, and confirm publication settings. When the owner approves a release, the application sends the selected video, thumbnail, captions, metadata, declarations, playlist assignments, and scheduling instructions to YouTube. YouTube makes a release available according to the owner’s visibility and schedule.

The owner runs the application in Google Colab and keeps project files in the owner’s Google Drive. The AI workflow can send scripts, selected source excerpts, or review media to Gemini when the owner runs those steps. The YouTube integration uses Google user data for channel and publication operations. OAuth credentials and YouTube owner readbacks are kept out of AI prompts. We do not sell Google user data or use it to serve advertisements.

Storage and protection

The one-time Windows helper stores the refresh credential in a private local project file with restricted Windows permissions. When the owner configures cloud access, the notebook reads the credential from Colab Secrets. The application saves publishing evidence in the private project folder in Google Drive. The resumable upload state is encrypted separately. The website source and public site contain no credentials, private media, or owner API records.

The application retains relevant YouTube readbacks to confirm a release and reconcile retries. The owner reviews stored YouTube API data and removes or refreshes it as required by the YouTube API Services Developer Policies. The application leaves this cleanup to the owner.

Revoke access or delete stored data

To revoke access, remove Horror Story Studio in your Google Account connections. The owner can then remove the local OAuth file and Colab Secret, and delete the relevant YouTube readbacks, downloaded caption copies, and upload state in the private project folder and its trash. The owner can also disconnect the separately authorized Drive credential.

To request deletion or ask about privacy, contact the maintainer through the public repository. Post only a request to arrange contact. Keep account identifiers, credentials and other private details out of public issues. The owner handles deletion directly. YouTube’s policies require deletion as soon as possible and within seven calendar days of a deletion request, or within 30 days of revocation through Google’s settings.

Deleting the application’s copies does not remove videos or other data held by YouTube. Manage those separately in YouTube Studio.

This website

This GitHub Pages site has no sign-in, forms, advertising, analytics scripts, or application cookies. GitHub provides the hosting and processes requests under its privacy statement. Google’s handling of data on its services is described in the Google Privacy Policy.
